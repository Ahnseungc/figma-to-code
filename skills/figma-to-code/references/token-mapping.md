# 토큰 매핑 상세 · 흔한 오매핑

예시는 Tailwind 유틸 이름을 쓰지만 원리는 어떤 DS에도 같다. 실제 이름은 프로젝트 토큰 맵을 따른다.

## 항목별 대조표

| 항목 | Figma에서 볼 값 | 코드에서 맞출 것 |
|---|---|---|
| 텍스트 스타일 | fontSize · lineHeight · letterSpacing · fontWeight **네 개를 한 세트로** | 네 값이 가장 잘 맞는 타이포 토큰 **하나** |
| 글자·아이콘 색 | fill · stroke · opacity | 시맨틱 색 토큰. 임의 Hex 금지 |
| 배경 | 루트 프레임 fill, 섹션별 fill | 루트 배경 토큰은 Figma 루트 fill과 1:1. "비슷한 회색"으로 바꾸지 않는다 |
| 테두리 | stroke 유무·두께·색 | **stroke가 있을 때만** border. `ul > li` 구조라는 이유로 추가하지 않는다 |
| 모서리 | cornerRadius, 모서리별 값 | 반경 토큰. 모서리별이면 개별 모서리 유틸 (아래 반경 절) |
| 그림자 | effects: x/y · blur · spread · color | 그림자 토큰. 없으면 `shadow-<기능>` 같은 의미 있는 유틸을 추가. 임의 `shadow-[...]` 금지 |
| 헤더 그림자 | 헤더 프레임 effect 유무 | effect가 없으면 그림자를 넣지 않는다 |
| 간격 | auto layout gap · padding (px) | px ÷ 간격 단위 → 토큰 |
| 여백 위치 | 어떤 프레임에 padding이 붙어 있는지 | footer에만 있으면 footer에만. 페이지 루트 전체 `pb-*`로 뭉뚱그리지 않는다 |
| 리스트 마커 | 점·숫자 marker 형태 | `list-disc`/점 요소. 세로 `border-l` 막대로 대체하지 않는다 |
| 하단 CTA | 버튼 컴포넌트 | DS Button 컴포넌트. variant 클래스 문자열만 조합해 흉내 내지 않는다 |

수치가 토큰과 정확히 맞으면 그 토큰만 쓴다. 어긋나면 가장 가까운 토큰을 고르고 근거를 남긴다. 차이가 크면 묻는다.

## 타이포 — 오매핑 원인 9가지

| # | 원인 | 막는 법 |
|---|---|---|
| 1 | MCP 참고 코드 복붙 (`text-[15px]`, `text-lg`, `font-bold`) | 참고 코드는 구조 힌트로만. 클래스는 전부 토큰으로 재작성 |
| 2 | `<h1>`·레이어 이름 "Heading"만 보고 h1 토큰 선택 | **수치**로 고른다. 제목처럼 보여도 Title/Body 토큰인 경우가 많다. DOM 태그(시맨틱)와 타이포 토큰은 별개 |
| 3 | fontSize만 맞추고 lineHeight·letterSpacing 무시 | 같은 20px라도 토큰마다 행간·자간이 다르다. 네 값을 세트로 비교 |
| 4 | 없는 variant 가정 (`-medium`) | 토큰 파일에 실제 정의됐는지 grep |
| 5 | 다른 프로젝트 습관 (`text-sm`, `font-semibold`) | 프로젝트 토큰만 |
| 6 | 토큰 + 임의 `leading-[…]` 이중 지정 | 다른 토큰이 더 맞는지 먼저 본다. 꼭 필요하면 이유를 남긴다 |
| 7 | 텍스트 스타일 **이름**만 믿음 ("Body/16"인데 로컬 override로 14px) | 해당 레이어의 **최종 수치** 기준 |
| 8 | 타이포 클래스와 색 클래스 중 하나 누락 (`text-` 접두가 둘 다일 때 흔함) | 타이포 토큰 + 색 토큰 둘 다 지정됐는지 확인 |
| 9 | 고정 폭 프레임의 `whitespace-nowrap` 누락 | 칩·카드 타이틀이 한 줄이면 nowrap. 한국어는 "~해요"만 다음 줄로 떨어지는 식으로 깨진다 |

## 간격 — 변수 이름의 숫자를 믿지 않는다

- Figma 변수 `spacing-200` 은 보통 20px다. 클래스 `gap-200`도, 관성적인 `gap-8`(32px)도 아니다.
- 순서: (1) 노드의 **px** 확인 → (2) ÷ 간격 단위 → (3) 토큰 확정.
- 참고 코드의 `gap-8`을 그대로 옮기지 말고 **그 프레임의** gap 값을 본다.
- 다섹션 스크롤 화면은 루트 gap과 섹션 래퍼 padding이 겹쳐 이중 여백이 되기 쉽다. Figma에 섹션 padding이 없으면 루트 gap만.
- MCP 참고 코드의 `var(--...)` 를 클래스에 그대로 넣지 않는다. `/`가 들어간 변수명은 CSS 파싱 오류를 낸다.

## 반경 — 개별 모서리 조합

말풍선처럼 "전체 8px, 한 모서리만 0"이면 `rounded-8 rounded-tr-0` 처럼 **개별 모서리** 유틸을 덮어쓴다.

- 개별 모서리 유틸이 단일 속성(`border-top-right-radius`)을 쓰는지 확인. 4값 shorthand로 정의돼 있으면 나중에 오는 규칙이 전체를 덮어 네 모서리가 다 0이 된다.
- `rounded-t-0` 같은 **방향** 유틸은 보통 shorthand라 전체 반경과 섞지 않는다.
- 클래스만 보고 끝내지 말고 DevTools computed `border-radius` 확인.

## 내용 폭 칩(태그·뱃지)

Figma에서 배경이 글자 길이만큼인 칩을 `flex-col` 안에 넣으면 기본 block이라 **카드 폭 전체 바**가 된다.

- `self-start` 또는 `w-fit` / `inline-flex`
- 높이는 메타데이터 padding 그대로 (3px면 3px). 옆 뱃지의 padding을 복사하지 않는다.
- 한글이 위로 붙고 아래만 비어 보이면 **자간 문제가 아니다**. line-height·글리프 메트릭 문제라 `leading-none` + 필요하면 `translate-y-px`.

## 모달

- 카드 루트 padding, 헤더↔버튼 gap, 타이틀↔부제 gap을 각각 수치로 대조한다.
- 카드에 padding이 있는데 버튼 영역 컴포넌트도 기본 padding을 가지면 **이중 들여쓰기**가 된다.
- 부제 줄바꿈: Figma 텍스트에 강제 줄바꿈이 있을 때만 `\n` + `pre-line`. 스크린샷에서 두 줄이어도 MCP 텍스트가 한 줄이면 프레임 폭에 의한 자동 줄바꿈이다. 폭을 맞추고 `\n`은 넣지 않는다.

## 아이콘

- 노드를 읽을 때 아이콘 인벤토리를 먼저 만든다. `.svg` URL이 없는 항목은 누락 후보로 표시하고 Copy as SVG / Export SVG로 보완.
- `viewBox` + 크기는 className, 색은 `currentColor`. width/height를 고정하면 래퍼에서 줄일 때 비율이 틀어진다.
- 지정된 노드가 있으면 "비슷한 기존 아이콘"으로 대체하지 않는다. 외곽선/채움, stroke 두께, viewBox를 대조.
- `<pattern>`/`<use xlink:href>` SVG는 참조 이미지가 빠지면 빈 아이콘이 된다. 렌더 확인 필수.
- 리스트 마커가 `2×22` 벡터로 나오면 스크린샷으로 점인지 막대인지 확정한다. 점이면 `래퍼(2×22) + 중앙 점(2×2)`.
